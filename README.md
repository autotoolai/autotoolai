## Claude 无限卡是什么

第三方订阅制 API 网关：订阅期内 Claude API **不按 token 计费**，一个 Key 接入 Claude Code / Cursor / Cline / Codex 等主流客户端。
接入只改两处——Base URL 与 API Key，不必换 SDK。
